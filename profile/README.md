# Routilet

面向学习与日常编程的轻量桌面工具。独立应用、按需安装、离线优先。

## 项目

| 项目 | 职责 | 状态 |
| --- | --- | --- |
| [Routilet](https://github.com/Routilet/routilet) | 统一应用管理、安装、更新与启动 | 规划中 |
| [Companion](https://github.com/Routilet/accoding-companion) | 课程管理、本地评测、OJ 提交 | 已有终端版本，规划 GUI |
| [Observer](https://github.com/Routilet/c-observer) | 直观观察程序执行，替代 printf 调试 | GUI 新版开发中 |
| [Exam Kit](https://github.com/Routilet/c-exam-kit) | 版本化代码资源与函数手册 | 已有发行 |

各应用独立维护、独立运行，可选协作。Routilet 是统一管理入口，而非应用持续运行的必要条件。当前仓库及 npm 包仍沿用原有名称；上表使用目标产品名称，不代表迁移已经完成。

Companion 为非官方课程辅助项目，与 ACCoding、北航无官方隶属关系。
