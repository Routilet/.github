# 任务 G：公共视觉规范草案

优先级：P1，可选，可由任务 F 负责人兼任。执行仓库：[Routilet/.github](https://github.com/Routilet/.github)。待分配。

## 目标

让 Routilet、Companion、Observer 在保持独立应用和窗口的情况下具有一致的视觉与交互语言。以轻量工具、信息清晰、键盘与鼠标均可高效使用为原则。

阅读 [共同决策](../ecosystem.md)，参考已有 Observer 界面（以其当前开发分支负责人提供的真实实现为准）及其他设计原型；不能因规范草案阻塞正在进行的开发。

## 内容

只规定必要的共同约定：系统字体、跟随系统的深浅色、基础色及成功/警告/失败状态、信息密度、间距、图标、按钮/输入框/表格、焦点和键盘操作、错误与进度提示、窗口标题及应用标识。注意中文、对比度和状态不能仅靠颜色区分。允许各应用根据任务调整布局；不强求同一组件实现。

## 交付及边界

独立分支新增 docs/visual-guidelines.md，简洁草案，必要时附小型示例；PR 供维护者评审。暂不建设 UI 库、公共 npm 包、独立设计仓库或复杂 token 系统，不修改各应用代码，不要求正在进行的 Observer 开发返工。待多个实际 GUI 成熟后再考虑提取复用组件。
