# Routilet 图标设计说明

## 理念
Routilet 的命名源于 routine。品牌的共同价值是减少人亲自执行的重复工作，使其专注于真正需要思考与创造的任务。母题为「归并」：多个相似单元，经由收束结构形成一个较高层、可复用的结果。主标识不是启动器的入口、字母 R 或网络拓扑。

## 图形
统一 128×128 SVG 画布、120×120 圆角底板（圆角 27）、高对比浅色前景及较柔和的连接色。优先辨认形态，色彩仅作辅助。无文字、渐变、投影或复杂纹理。保持小尺寸可读性；16、24、32 px 是实际验收目标，并非已完成真机验证。

| 产品 | 形态 | 底色 | 连接色 |
|---|---|---|---|
| Routilet | 三个方块归并为一个结果块 | #225344 | #9AC4AD |
| Companion | 三层代码片段折叠、整理为结果 | #28558B | #9DBDE1 |
| Observer | 三条执行信息汇聚为可理解的结果 | #584785 | #B7A5DC |
| Exam Kit | 六个资源单元收束为工具包 | #996238 | #D8B292 |
| Accoding Adapter | 两个端点汇合至适配接口 | #426780 | #A8C5D5 |

统一前景 #F5F5EF。颜色不表达产品状态。Exam Kit 暂为系列资源图标，不意味着独立应用。

## 维护
组织仓库 `assets/icons/` 中的 SVG 为设计源文件；各应用仓库保存本地副本。直接从 SVG 生成平台资源，勿从截图裁切。Windows 使用多尺寸 ICO 嵌入 EXE，macOS 使用 ICNS 和 Info.plist，在签名前完成打包；Web 使用 SVG。可根据平台安全区做尺寸适配，但不随意修改母题。初版采用扁平矢量重绘，不追求拟物效果。

控制设计投入：目前定稿用于实际产品，若小尺寸或系统显示有明显问题再改，不做无目的的品牌迭代。
